# HR Analytics – Attrition Analysis

## Overview
- Analyze employee attrition patterns to improve retention strategies. 
- This project helps organizations understand why employees leave and how to implement effective retention initiatives.

## Objectives
- Identify key reasons for high employee turnover, 
- predict which employees are at risk of leaving,
- and develop data-driven HR interventions to improve retention rates.

## Methodology
- Comprehensive exploratory data analysis of HR metrics
- Feature importance analysis to identify attrition factors
- Random Forest classification for prediction modeling
- Cross-validation and model performance evaluation
